# Neon Rift: Arena

A self-contained browser arena game built with HTML5 Canvas and JavaScript.

## Controls
- WASD: move
- Mouse: aim / left click to fire
- Shift: dash
- Esc: pause

## Features
- Escalating enemy waves
- Boss waves every 5th wave
- XP and level progression
- Upgrade choices
- Coins and collectible energy cores
- Dash ability
- Screen shake, particles, glow and animated effects
- Responsive layout
- Local best score

## Folder structure

```text

```

No external libraries or game servers are required.
